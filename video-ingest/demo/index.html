video-ingest demo

Pick a video. The library normalizes it into a server-safe intermediary chosen by browser capability:

  • av1 lane — AV1-in-WebM (compact; server re-decodes with rav1d).
  • frames lane — 320p APNG + separate Opus audio (universal fallback).

Serve this over http/https (not file://) so WebCodecs is available. From the project root: npm run demo, then open the printed URL.
