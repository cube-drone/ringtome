# rettro

## How Do I Dev?

This depends on Rust and node being installed.

* `cargo run` in `api` to make the server turn on
* `npm run watch` in `api/js` to make the JS auto-compile
* `npm run csswatch` in `api/js` to make the CSS auto-compile
* `mocha` in `api/js` to run the tests (this needs the server to be on)
