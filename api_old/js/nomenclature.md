
## I need WORDS for stuff

* A **Page** is a complete standalone unit: routes can point to **Page**s.
* A **Layout** is a reusable shell or frame for content.
* A **Section** is a block of content that can be used in a Page or Layout.
  * A **Form** is a Section, but specifically describing ... you know, a form!
* A **Widget** is a reusable component like "User" or "Community" that can go in many places.
* A **Bip** is a reusable style element, like a Button, Div, or Input
